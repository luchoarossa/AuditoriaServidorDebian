# 📌 Auditoría de Seguridad y Pentesting en Servidor Debian

🔍 **Proyecto Final de Ciberseguridad**  
Este proyecto incluye un informe detallado de pentesting, cumplimiento de los estándares SGSI (Seguridad de la Información y Gestión de Sistemas) y un plan de recuperación estructurado para mitigar vulnerabilidades.  

## 🚀 Tecnologías Utilizadas  
- 🐧 **Kali Linux** – Para realizar auditorías de seguridad y pruebas de penetración.  
 

## 📖 Descripción  
El objetivo del proyecto es identificar, evaluar y fortalecer la seguridad de un servidor Debian, garantizando su resistencia frente a amenazas cibernéticas. Se llevó a cabo un análisis de vulnerabilidades con herramientas especializadas, generando un informe detallado junto con un plan de remediación.
