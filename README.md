# Auditoría de Seguridad y Pentesting en Servidor Debian

## Proyecto Final de Ciberseguridad

Este proyecto consiste en una auditoría de seguridad y pentesting exhaustiva realizada en un servidor Debian, culminando en un conjunto de informes detallados disponibles en este repositorio. El objetivo principal fue identificar, evaluar y mitigar vulnerabilidades, asegurando el cumplimiento de los estándares SGSI (Seguridad de la Información y Gestión de Sistemas).

## Tecnologías y Metodologías Clave

* **Extracción de Evidencias con Autopsy:** Se realizó un análisis forense detallado utilizando Autopsy para identificar y extraer evidencias relevantes del sistema.
* **Evaluación de Vulnerabilidades con Nmap, NSE y Nessus:** Se emplearon estas herramientas para realizar un escaneo profundo del servidor, identificando vulnerabilidades potenciales y su criticidad.
* **Recopilación de Información a través de OSINT:** Se aplicaron técnicas de Inteligencia de Fuentes Abiertas (OSINT) para obtener información valiosa sobre el objetivo, mejorando la efectividad del pentesting.
* **Explotación de Vulnerabilidades con Metasploit e Hydra:** Se realizaron pruebas de penetración utilizando Metasploit para explotar vulnerabilidades identificadas y Hydra para ataques de fuerza bruta, evaluando la resistencia del sistema.
* **Configuración de Firewalls y Tráfico de Red (IPtables, UFW):** Se revisó y fortaleció la configuración de firewalls y el control del tráfico de red utilizando IPtables y UFW, mejorando la seguridad perimetral.
* **Monitorización con Wireshark y Wazuh (SIEM, IDS/IPS):** Se implementó una solución de monitorización utilizando Wireshark para el análisis de tráfico y Wazuh como SIEM e IDS/IPS, permitiendo la detección y respuesta a incidentes de seguridad en tiempo real.

## Informes Detallados

Este repositorio contiene informes completos que documentan cada fase del pentesting, incluyendo:

* **Informes de Escaneo de Vulnerabilidades:** Resultados detallados de los escaneos realizados con Nmap, NSE y Nessus.
* **Informes de Análisis Forense:** Evidencias extraídas y analizadas con Autopsy.
* **Informes de Pentesting:** Descripción de las pruebas de penetración realizadas con Metasploit e Hydra, incluyendo vulnerabilidades explotadas y su impacto.
* **Informes de Configuración de Seguridad:** Análisis y recomendaciones sobre la configuración de firewalls y el control de tráfico de red.
* **Informes de Monitorización:** Configuración y resultados de la monitorización con Wireshark y Wazuh.

## Cómo Utilizar Este Repositorio

1.  **Explorar los Informes:** Navega por los diferentes directorios para acceder a los informes de cada fase del proyecto.
2.  **Analizar los Resultados:** Revisa los informes para comprender las vulnerabilidades identificadas, las pruebas realizadas y las recomendaciones de seguridad.
3.  **Utilizar como Referencia:** Este repositorio puede servir como una guía práctica para realizar auditorías de seguridad y pentesting en servidores Debian.
